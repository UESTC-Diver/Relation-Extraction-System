## 4. P0 优化内容

### 4.1 指代消解

在关系抽取前增加一层回指解析，把回指词替换成伪实体（span 指向回指词本身，文本 / 类型 / id 指向真实实体），再参与后续匹配：

| 回指类型 | 词表 | 解析策略 |
| --- | --- | --- |
| 群体 | 双方 / 两者 / 两家公司 / 三方 / 各方 | 取最近两个显著实体（人物/机构），按提及顺序组成实体对 |
| 序数 | 后者 / 前者 | 回指最近实体对的第二个 / 第一个 |
| 定指 | 该公司 / 该集团 / 该工厂 / 该平台 … | 优先回指语篇主事主体，退回最近机构 |
| 事件 | 此举 / 本次收购 / 此次合作 / 此次投资 … | 按事件类型跟随最近一次对应关系的主事者，否则跟随上一句主语 |

同句实体优先；同句不足两个时，从历史实体栈补齐。修复的典型用例：

| 文本 | 优化前 | 优化后 |
| --- | --- | --- |
| "宁德时代将为该工厂供应磷酸铁锂电池，**双方**已签订长期供货协议" | 漏抽 sign | 宁德时代 —签署协议→ 特斯拉 |
| "腾讯起诉字节跳动…此前，**双方**已在多个领域展开竞争" | 漏抽 compete | 腾讯控股 —竞争→ 字节跳动 |
| "华为与京东方签署供货协议，**后者**将为新机供应 OLED 屏幕" | 方向反转为 华为→京东方 | 京东方 —供应→ 华为 |
| "阿里巴巴已投资饿了么多轮，**双方**在即时配送领域长期合作" | 漏抽 cooperate | 阿里巴巴 —合作→ 饿了么 |

### 4.2 关系方向修正

`SPECIAL_PATTERNS` 中 "A 成为 B 的全资子公司" 的占位符顺序写反了，导致输出 "腾讯—子公司→搜狗"。修正为 (头=A, 尾=B) 后，c01 的 `subsidiary` 由 0 分变为满分。

### 4.3 触发词容错与隐性表达

- **副词插入容错**：扫描前先剥离触发词内部夹入的副词（"总部仍位于"→"总部位于"、"已正式签署"→"签署"），并在原文坐标上还原触发片段。否定词（未 / 没 / 不 / 尚未）不在剥离表中，避免把否定句误判为肯定关系。
- **协议名排除**："签署供货协议 / 采购合同"里的"供货 / 采购"不再当作供应关系触发词。
- **隐性竞争表达**：补充"挤压 / 蚕食 / 抢占"等触发词。
- **并列宾语展开**："挤压比亚迪和蔚来汽车的市场份额"同时产出两条 compete。
- **分句主语继承**："腾讯已投资搜狗多年，**并**与搜狐签署协议"的主语沿用前一分句的腾讯，不再把"搜狗"当成签署方。

## 5. 剩余错误分析

### 5.1 漏抽：领域词典未覆盖（4 条）

c05「恒瑞医药与默克合作」是唯一的医药行业文本，也是唯一的零输出段：

| 应抽 | 原因 |
| --- | --- |
| 恒瑞医药 —签署协议→ 默克集团 | "恒瑞医药"未被机构词典或后缀规则识别（"医药"不在机构后缀表中） |
| 恒瑞医药 —合作→ 默克集团 | 同上 |
| 恒瑞医药 —总部位于→ 江苏连云港 | 同上 |
| 孙飘扬 —任职于→ 恒瑞医药 | 机构未识别，任职关系失去尾实体 |

这是规则式方法的固有边界——效果与词典覆盖面强相关。把"医药 / 制药 / 生物"等加入机构后缀表，或加入 `恒瑞医药 / 默克集团` 词条后，该段 4 条关系基本都能被现有模板覆盖，是下一步投入产出比最高的修补。

### 5.2 误抽：金标集漏标（3 条）

以下三条都是文本明确陈述、且符合既有关系类型定义的关系，但金标集未收录：

| 用例 | 系统输出 | 原文依据 |
| --- | --- | --- |
| c04 | 宁德时代 —供应→ 磷酸铁锂电池 | "宁德时代将为该工厂供应磷酸铁锂电池" |
| c04 | 特斯拉 —投资→ 上海临港新片区 | "特斯拉宣布在上海临港新片区投资建设第二座超级工厂" |
| c09 | 小米 —总部位于→ 北京市昌平区 | "小米集团宣布将集团总部迁至北京市昌平区" |

本次评测未修改金标集，因此这 3 条仍按误抽计入。若补齐标注，Precision 将升至 1.00，F1 约为 0.96（Recall 仍受 c05 限制）。

### 5.3 仍存在的边界

- 第三人称代词（他 / 她 / 其）与长距离跨段回指未处理。
- "A 与 B 收购 C"这类联合主语结构仍只取最近的一方作为收购方。
- 触发词容错只覆盖副词插入，不处理倒装、省略等更自由的句式。

## 6. 结论

P0 优化后，规则式方法在本评测集上达到 **P 0.936 / R 0.917 / F1 0.926**，10 段中 7 段完全正确。语序固定的关系（任职、创立、毕业、收购、子公司）接近或达到满分；此前因指代、方向、触发词插入造成的损失已基本消除。

剩余召回缺口集中在**领域词典覆盖**（c05 一段贡献全部 4 条漏抽），下一步优先补领域实体后缀与自定义词典；精确率方面，剩余 3 条"误抽"实际是金标漏标，说明在该数据集上系统输出已接近标注上限。
